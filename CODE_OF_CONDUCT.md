# Contributor Covenant 3.0 Code of Conduct

This project adopts the [Contributor Covenant 3.0 Code of
Conduct](https://www.contributor-covenant.org/version/3/0/). It applies to all
project spaces and to official representation of this project in public.

Please report a possible violation privately to the project maintainers through
the contact details of this repository. Reports are handled with care for safety
and confidentiality.
